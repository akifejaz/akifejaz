- Sr. Engineer at [10xEngineers](https://10xengineers.ai), working on RISC-V software enablement
- Official [Committer](https://projects.eclipse.org/projects/iot.threadx/CM/akifejaz) at the [Eclipse Foundation](https://www.eclipse.org), maintaining the RV64 & RV32 ports of [Eclipse ThreadX](https://github.com/eclipse-threadx)
- Official Maintainer at the [seL4 Foundation](https://sel4.systems/Foundation/), maintaining [Banana Pi BPI-F3](https://docs.sel4.systems/Hardware/bananapi-f3.html) (SpacemiT K1) board support in the [seL4 Microkernel](https://github.com/seL4/seL4)
- Contributor to the [Linux Kernel](https://kernel.org), with the `spi: cadence-quadspi` patch merged in v6.20 
- Developer Eclipse Foundation backedup project [**ATESOR**](https://eclipse.dev/atesor/), an agentic AI system for autonomous RISC-V software porting
- Developer & maintainer of [Cloud-V](https://cloud-v.co), a RISC-V CI platform (get a free RISC-V machine [here](https://cloud-v.co/contactus))
- Wrote firmware for RISC-V real hardware: Banana Pi BPI-F3, Milk-V Jupiter, StarFive VisionFive 2
- Built a RISC-V hardware benchmark platform (see [here](https://cloud-v.co/risc-v-comparison))
- Write to teach, technical articles on Linux, Systems & AI
